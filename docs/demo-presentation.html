Live commerce · Django · Railway

Kistie-Store

One storefront: / redirects to /shop/. Multi-currency cart and checkout, Django admin, staff portal + audit log, JSON API under /api/inventory/ (REST prefix—not a second UI), CI-tested deploys—built for a real retail operation.

Storefront

Shop

The only customer browse/buy screen — /shop/ (backend/core/templates/core/shop.html). Filters, EU sizing, quick-view, add to cart. No separate catalog or inventory pages; legacy /catalog/ and /inventory/ redirect here for old bookmarks only.

Customer journey

Cart & checkout

/cart/ and /checkout/ — line items, live FX (USD / EUR / KES / UGX), MTN, Airtel, Pesapal. Auth at /signup/, /login/; order history at /account/orders/.

Django admin

Operations

Staff portal

Staff sign-in → dashboard (/staff/dashboard/) — orders snapshot, low-stock alerts. Superusers: audit trail at /staff/audit-log/.

Engineering

API & delivery

  • Django REST Framework at /api/inventory/ — products/, categories/, payment stub; public reads, staff-only writes. Path name only—not a duplicate storefront.
  • GitHub Actions CI — install root requirements.txt, python manage.py test from backend/, on every push to main.
  • PostgreSQL on Railway; Gunicorn + WhiteNoise; health/ for uptime checks.
